# decls_extraction

[![License](https://img.shields.io/badge/license-Custom--SA-%231b25e5)](https://raw.githubusercontent.com/Python-Components-Group/decls_extraction/refs/heads/main/LICENSE)

A Python component for code declarations extraction (used in [GenTestsAILib](https://github.com/codesavant23/gentestsai/))

## How to get the component

### Latest stable release

You can find the binaries of the component in the [release](https://github.com/Python-Components-Group/decls_extraction/releases) section of this repository

### Latest build

#### Installation

  ```python
  pip install git+https://github.com/Python-Components-Group/decls_extraction
  ```

#### Update

  ```python
  pip install git+https://github.com/Python-Components-Group/decls_extraction --upgrade
  ```
